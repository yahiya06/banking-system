# Banking System (Microservices)

A microservices-based banking backend built with Java. Each banking function runs as an independent service behind an API Gateway.

**Status: In progress**

## Services

- [ ] api-gateway
- [ ] account-service
- [ ] transaction-service
- [ ] payment-service
- [ ] fraud-detection-service
- [ ] notification-service

## Run

```bash
git clone https://github.com/yahiya06/banking-system.git
cd banking-system
docker compose up --build
```
